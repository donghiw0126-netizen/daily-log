# Daily Log

매일 할 일 체크, 공부 계획·복습, 가계부, 짧은 일기를 한곳에 담은 생활 기록 웹앱이에요. 서버 없이 돌아가고, 기록은 **쓰는 브라우저에만** 저장돼요.

## 기능 (v0.8.0)
- **오늘(홈)**: 요약 카드(습관·공부·지출·기분), 오늘의 습관·공부, 이번 주 흐름, 오늘 쓴 돈, 오늘의 한 줄. 컴퓨터는 왼쪽 메뉴, 폰은 아래 탭 바
- **습관**: 습관 추가·이름 바꾸기·순서 바꾸기·삭제, 날짜별 체크, 연속 기록 🔥, 최근 7일 표시. 📅 요일 지정(월·수·금, 평일, 주말 — 쉬는 날은 연속 기록이 끊기지 않음). 오늘의 공부 분량도 함께 보여요
  - 하루 여러 번 하는 습관: 하루 횟수·단위를 정하면(예: 물 하루 3잔) 누를 때마다 1씩, 다 채우면 완료. − 로 한 번씩 취소
- **공부**: 단어 카드(`단어 - 뜻` 붙여 넣기) 또는 책·강의 분량(페이지·강·문제·단원)을 목표로 넣으면
  - 하루 분량 = 남은 양 ÷ 남은 날 × 내 수준 배율 (처음 100% · 조금 알아요 120% · 잘 알아요 140%)
  - 전날 복습 정답률 90% 이상이면 배율 +5%, 70% 미만이면 −5% (60%~200%), 목표일을 못 맞출 것 같으면 경고
  - 간격 반복 복습: 1 → 2 → 4 → 7 → 15 → 30일 뒤 (기억남/헷갈림/까먹음), 끝까지 기억나면 '완전히 외움'
  - ⌨️ 직접 쳐서 맞히기 (단어 복습): 뜻을 보고 단어를 입력 → 정답 / 한두 글자 오타는 '헷갈림' / 틀림. 다른 정답을 썼다면 '사실 맞았어요'
- **가계부**: 지출/수입 기록(분류·메모), 월별 수입·지출·남은 돈, 분류별 지출 막대
- **쇼핑 리스트** (가계부 안): 마트별 품목·분류·가격, 체크하면 그 날짜 가계부에 고른 분류의 지출로 자동 기록(체크를 풀면 기록도 지움), 산 것 정리하기, 가격을 누르면 고치기(가계부 금액도 함께)
- **⏱ 집중 타이머** (공부 탭·홈): 집중 25분/50분, 휴식 5분, ✏️ 직접 설정(1~180분). 끝까지 마친 집중 시간이 날짜별로 쌓이고, 끝나면 소리·진동
- **🌙 화면 모드**: 설정에서 기기 설정 따라 / 밝게 / 어둡게
- **앱처럼 설치**(PWA): 설정 → 📲 앱처럼 설치하기. 홈 화면 아이콘, 인터넷 없이도 열림
- **일기**: 날짜별 기분 이모지와 글, 자동 저장, 이번 달 일기 목록
- **설정**: 백업 파일(JSON) 내려받기와 가져오기, 모두 지우기
- 위쪽 ◀ ▶ 로 지난 날짜의 기록도 보고 고칠 수 있어요 (미래 날짜는 막혀 있어요)

## 실행
```
npm start        # http://localhost:8002 에서 열기
npm test         # 계산 규칙 테스트
```

## 파일
- `logic.js`: 날짜, 연속 기록, 월 합계, 백업 검사 같은 순수 로직 (테스트 대상)
- `app.js`: 화면 동작
- `index.html`, `styles.css`: 화면
