# Daily Log

매일 할 일 체크, 가계부, 짧은 일기를 한곳에 담은 생활 기록 웹앱이에요. 서버 없이 돌아가고, 기록은 **쓰는 브라우저에만** 저장돼요.

## 기능 (v0.1.0)
- **습관**: 습관 추가·이름 바꾸기·순서 바꾸기·삭제, 날짜별 체크, 연속 기록 🔥, 최근 7일 표시
- **가계부**: 지출/수입 기록(분류·메모), 월별 수입·지출·남은 돈, 분류별 지출 막대
- **일기**: 날짜별 기분 이모지와 글, 자동 저장, 이번 달 일기 목록
- **설정**: 백업 파일(JSON) 내려받기와 가져오기, 모두 지우기
- 위쪽 ◀ ▶ 로 지난 날짜의 기록도 보고 고칠 수 있어요 (미래 날짜는 막혀 있어요)

## 실행
```
npm start        # http://localhost:8002 에서 열기
npm test         # 계산 규칙 테스트
```

## 파일
- `logic.js`: 날짜, 연속 기록, 월 합계, 백업 검사 같은 순수 로직 (테스트 대상)
- `app.js`: 화면 동작
- `index.html`, `styles.css`: 화면
